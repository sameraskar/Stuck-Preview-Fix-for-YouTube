# Store assets

- `logo-300.png`: 300×300 listing logo for Microsoft Edge Add-ons.
- `small-promo-440x280.png`: small promotional tile size used by both Edge Add-ons and Chrome Web Store.
- `large-promo-1400x560.png`: large/marquee promotional tile.
- `screenshots/`: instructions for capturing a real 1280×800 browser screenshot before Chrome Web Store submission.

The extension icon is deliberately abstract and does not use the YouTube logo or YouTube's red play-button trade dress.

- `assets/brand/icon-source.svg`

- `scripts/generate_assets.py`
