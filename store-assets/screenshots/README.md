# Store screenshot instructions

Do not submit a fabricated screenshot as if it were the live product.

For Chrome Web Store submission, capture the current browser UI after installing the generated extension:

1. Use a 1280x800 browser window or crop to 1280x800.
2. Open YouTube Home or a channel's Videos tab.
3. Enable Video previews / inline playback.
4. Start a card preview.
5. Demonstrate the new-tab action and the stopped preview in the original tab.
6. Add only minimal callout text if needed.
7. Keep the extension's own branding separate from YouTube branding.

Edge screenshots are optional, but the same real screenshot can be reused if Partner Center accepts its dimensions.
