# Privacy Policy

**Stuck Preview Fix** does not collect, store, sell, share, transmit, or analyze personal data or browsing history.

## What the extension accesses

The extension runs only on `https://www.youtube.com/*` and observes mouse/context-menu events on video cards so it can stop an inline preview when a new-tab action leaves that preview playing.

It may inspect the local page DOM and pause the inline `<video>` element inside the clicked card. This processing happens entirely inside the browser tab.

## Data collection

- No personal information is collected.
- No browsing history is collected.
- No analytics or telemetry is used.
- No cookies or identifiers are created by the extension.
- No extension storage is used.
- No network requests are made by the extension.
- No data is sent to the developer or any third party.

## Permissions

The extension requests no Chrome/Edge extension API permissions. Its only site access is the static content-script match for `www.youtube.com`, which is necessary for its single function.

## Changes

If a future version changes its data practices, this policy and the store disclosures must be updated before that version is published.

For privacy questions, open an issue in the public GitHub repository after replacing the repository placeholder in this project with your actual GitHub URL.
