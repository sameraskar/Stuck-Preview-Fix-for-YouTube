# Changelog

All notable changes to this project will be documented here.

## [1.0.0] - 2026-08-28

### Added

- Manifest V3 Chrome/Chromium/Edge extension.
- Middle-click (`auxclick`, button 1) cleanup for stuck video-card previews.
- Right-click (`contextmenu`) cleanup without blocking the native menu.
- Scoped preview `<video>` pause that avoids the main watch-page player.
- Pointer/mouse-leave cleanup plus neutral app-shell click fallback.
- Three short cleanup passes for asynchronous YouTube DOM changes.
- Abstract non-YouTube-branded icon set.
- Chrome/Edge store assets and submission documentation.
- Tampermonkey/Violentmonkey userscript version.
- GitHub issue templates and CI build validation.
