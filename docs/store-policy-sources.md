# Official publishing references checked for this release

These were checked while preparing version 1.0.0 on 2026-08-28. Store policies change, so re-check them before a future release.

## Microsoft Edge

- Publish a Microsoft Edge extension: https://learn.microsoft.com/en-us/microsoft-edge/extensions/publish/publish-extension
- Overview of Microsoft Edge extensions: https://learn.microsoft.com/en-us/microsoft-edge/extensions/
- Port a Chrome extension to Microsoft Edge: https://learn.microsoft.com/en-us/microsoft-edge/extensions-chromium/developer-guide/port-chrome-extension
- Manifest V3 guidance: https://learn.microsoft.com/en-us/microsoft-edge/extensions/developer-guide/manifest-v3
- Edge Add-ons developer policies: https://learn.microsoft.com/en-us/legal/microsoft-edge/extensions/developer-policies

## Chrome Web Store

- Supplying images: https://developer.chrome.com/docs/webstore/images
- Complete listing information: https://developer.chrome.com/docs/webstore/cws-dashboard-listing
- Chrome Web Store program policies: https://developer.chrome.com/docs/webstore/program-policies
- User data/privacy requirements: https://developer.chrome.com/docs/webstore/user_data

## YouTube branding

- YouTube API Services Branding Guidelines: https://developers.google.com/youtube/terms/branding-guidelines

The product name and icon avoid YouTube branding. The listing text may descriptively state that the extension works on YouTube, while the repository includes a non-affiliation trademark notice.
